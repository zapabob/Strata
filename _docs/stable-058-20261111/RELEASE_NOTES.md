# Hakua / Strata 0.5.8

This Windows stable release repairs the four retained extended tests for long
conversations, pre-send compaction, explicit /compact and search-heavy Plan
guards. The actual Harness child now receives the selected filtered environment;
fixtures own their profile and skill roots. The related actual-Harness group
passed 43 tests with no failures or skips against a synthetic model API.

CI also verifies independent app, Control and engine versions, complete
translation catalogs and platform fixtures. Windows ACL assertions compare
resolved identities, and existing image files are fully hashed on rescan even
after same-size edits with restored timestamps. Test memory profiles contain
synthetic data only. External Hermes-plugin checkout tests are explicitly opt-in.

The app retains /btw subagents, /deepresearch, RustXNG 0.31.1 Full and workflow
skill learning/application. App, Terminal, Control and native engine use the
coordinated SemVer 0.5.8. Control and native packages are newly built, signed
and checked; older versions retain their original identities. See QUALITY.json,
SOURCE.json and the verification record for the
exact source, CI results, packaged checks and installed WebView2 observations.
Synthetic model responses do not qualify native model quality, full-window
generation, concurrent GPU execution or general autonomous research quality;
releaseQualified remains false.

Download Strata-0.5.8-windows-x64-setup.exe and verify SHA256SUMS.txt. The
Strata-0.5.8-windows-x64.tar.7z bundle contains the same current-user Tauri NSIS
installer, signed components, instructions, RustXNG corresponding source,
attribution and internal checksums. Models, credentials and personal data are
excluded. Finish requests, unload models, back up user data and quit Strata
including its tray before overwriting. Installer Windows code signing is absent;
component/feed signatures are independent.
