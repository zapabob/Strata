## Decisions

The private GGML custom bridge checks the exact callback before reading userdata. Q and the packed immutable parameter bank are real GGML inputs. CPU controllers are constructed per layer/head from the verified sidecar. CUDA uses separately compiled `spin8_cuda` and the reviewed batched API on `ctx.stream()`. Per-context/per-device persistent error state is allocated by the actual executing CUDA backend. It is zeroed on its caller stream once, remains sticky, and is read after graph completion. Backend device selection is restored after read/free. CUDA graph capture is disabled for this private custom operation so captured launches cannot bypass host checks or actual dispatch counters. Ordinary GGML graph reuse remains enabled.

The full/sequence state routes use a bounded complete provenance header before memory deserialization. A prefix reader replays the original bytes for disabled legacy state and detects enabled sequence state in off contexts. A mismatch clears hybrid memory and marks an active context unusable. The initial support scope is qwen35 normal attention, one sequence, explicit flash-attention choice, no shared-parent/MTP, no live auxiliary adapter mutation, and no external K mean-center bias. Device-resident sequence serialization is explicitly rejected before legacy ownership assertions; it is not claimed supported.

Model SHA values are computed from the loader's actual file handles in split order, with bounded 1 MiB buffering. Normal loading does not hash when disabled. Direct-I/O hashing and metadata overrides are rejected when opted in. mmap external modification after hashing remains a documented limitation. Profile/position encodings are versioned, fixed little-endian integers/F32 bit patterns, with geometry and resolved parameters. Inspection exports their actual bytes and digests as JSON for the Python writer.
